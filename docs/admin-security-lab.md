# 관리자 웹 취약점 실습 모드

기존 `admin.airlab.test` 관리자 화면 안에서 합성 데이터만 사용해 웹 취약점을
점검하는 교육 기능입니다. 운영 예약·문의·승무원·협력사 데이터와 실제 관리자
비밀번호는 실습 API에서 조회하거나 변경하지 않습니다.

## 활성화 조건

WildFly 환경 파일에 다음 키가 있을 때만 실습 API가 등록됩니다.

```text
ADMIN_LAB_ENABLED=true
```

실습을 종료할 때 값을 `false`로 바꾸거나 키를 제거하고 WildFly를 재시작하면
`/api/admin/lab/**`는 모두 닫힙니다.

## 관리자 역할

| 역할 | 정상 권한 |
| --- | --- |
| `SUPER_ADMIN` | 모든 관리자 기능 및 감사로그 |
| `OPERATOR` | 예약·문의·승무원·협력사 운영 기능 |
| `AUDITOR` | 감사로그 조회 |

`보안 취약점 실습` 메뉴는 권한 검증 누락을 재현하기 위해 세 역할 모두 접근할
수 있습니다. 실습 결과로 반환되는 개인정보·계좌·토큰·경로는 전부 합성
데이터입니다.

## 실습 시나리오

| ID | 취약점 | 점검 방법 |
| --- | --- | --- |
| LAB-01 | IDOR/BOLA | 프로필 ID를 변경해 다른 합성 관리자 정보 조회 |
| LAB-02 | 불충분한 권한 검증 | 제한 역할로 합성 전체 관리자 내보내기 실행 |
| LAB-03 | 상세 오류 정보 노출 | verbose 응답에서 합성 내부정보 확인 |
| LAB-04 | 약한 비밀번호 정책 | 4자 문자열이 정책 검사를 통과하는지 확인 |

## 실습 계정 생성 원칙

실습 계정 비밀번호는 문서나 Git에 기록하지 않습니다. 서버 환경변수
`ADMIN_LAB_OPERATOR_PASSWORD`, `ADMIN_LAB_AUDITOR_PASSWORD`로만 전달하면
최초 부팅 시 BCrypt 해시로 저장됩니다. 비밀번호 환경변수는 계정 생성 확인 후
환경 파일에서 제거하는 것을 권장합니다.

## 종료 점검

1. `ADMIN_LAB_ENABLED=false` 설정
2. WildFly 재시작
3. `/admin/api/admin/lab/overview`가 404인지 확인
4. 필요 시 `lab_operator`, `lab_auditor` 계정을 비활성화
5. 합성 플래그 캡처와 점검 결과만 증빙 폴더에 보관
